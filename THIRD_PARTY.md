# Third-party code

Code in this repository that is ported from other projects, with its
license. Test data fetched by `tools/fetch_gba_tests.py`,
`tools/fetch_snes_tests.py`, `tools/fetch_nes_tests.py`,
`tools/fetch_gc_tests.py`, `tools/fetch_nds_tests.py` and
`tools/fetch_n64_tests.py` is not committed; its sources and licenses are
recorded in `roms/gba/MANIFEST.json`, `roms/snes/MANIFEST.json`,
`roms/nes/MANIFEST.json`, `roms/gc/MANIFEST.json`, `roms/nds/MANIFEST.json`
and `roms/n64/MANIFEST.json`.
